# Bophelo Mother & Child Healthcare Centre

- **Project:** Bophelo Mother & Child Healthcare Centre Website
- **Location:** Polokwane & Seshego, Limpopo, South Africa

---

## Project Overview
This website provides key information, healthcare services, interactive enquiry forms with client-side form validation, and branch location mapping for the Bophelo Mother & Child Healthcare Centre. Designed with a calming **Soft Lilac (`#f3e8ff`)** and **Electric Indigo (`#4f46e5`)** color palette, the site bridges community healthcare needs with a modern, accessible digital platform.

---

## Core Goals & Obstacles

### Goals
1. **Make Healthcare Easy to Find:** Help mothers and families in Limpopo easily view services like maternal care and child vaccines online.
2. **Collect Inquiries Smoothly:** Allow users to book appointments or ask questions online using working contact forms that check for mistakes automatically.
3. **Work Well on All Devices:** Ensure the website looks good and is easy to read on both mobile phones and computer screens.
4. **Build a Professional Brand:** Use a clean layout with Soft Lilac and Electric Indigo colors to make the clinic look modern and trustworthy.

### Obstacles
1. **Setting Up Form Validation:** Getting the JavaScript code to correctly flag empty fields (like missing names or dates) and check for 10-digit phone numbers.
2. **Making the Layout Responsive:** Adjusting the CSS code so that the navigation menu and maps stack nicely on small screens instead of breaking.
3. **Path Mismatches:** Fixing broken CSS links (like linking `styles.css` correctly) so the page styling and colors always display as intended.
4. **Embedding Accurate Maps:** Adding two separate Google Maps side-by-side for the Polokwane and Seshego branches without making the page load slowly.
